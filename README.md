# CS210AirgeadBanking
Project completed as part of CS210: Programming Languages at SNHU. Takes a number of years, initial investment amount, monthly deposit amount, and annual interest rate. It returns a table of account balances compounded yearly both with and without monthly deposits. It has a menu for changing any value and reprinting the tables.

Account.h and Account.cpp: comprise the Account class which holds and calculates values. Values are stored in a vector.

UserInterface.h and UserInterface.cpp: holds various functions which print the tables, menu, and overall user interface.
